# SneppX CLI Docs

- `sneppx-train` - launch training runs.
- `sneppx-serve` - serve a model over HTTP.
- `sneppx-eval` - evaluate checkpoints.
- `sneppx-quantize` - INT8/INT4/FP8 quantization.
- `sneppx-rlhf` - RLHF fine-tuning.

## Shared flags

- `--config` YAML config path
- `--device cpu` (GPU optional)
- `--out` output directory
